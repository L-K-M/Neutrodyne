# M8 Atom fixtures

`m8-atom.xml` is synthetic, written 2026-10-19. It mirrors the documented
YouTube Atom namespaces, author, video IDs, media description, views and
Shorts links, with missing and malformed published dates. It contains no
captured channel text. Tests generate 15-entry windows and change updated,
views and variant responses without retaining large recordings. The same
resource is packaged for JVM and Android host parser replay.
